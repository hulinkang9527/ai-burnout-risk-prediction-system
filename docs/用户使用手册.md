# 用户使用手册

## 1. 系统定位

“知衡”用于毕业设计中的教育支持研究。结果不构成心理或医学诊断，也不得作为处分依据。真实使用前请取得学校许可和知情同意。

## 2. 启动

1. 进入`02_系统源码/backend`。
2. 创建Python环境并安装`requirements.txt`。
3. 确认`03_数据分析/artifacts`内模型与JSON齐全；若没有，先运行`03_数据分析/analysis_pipeline.py`。
4. 执行`run.ps1`或README中的启动命令。
5. 浏览器访问控制台显示的本地地址，先确认顶部为“服务在线”。

## 3. 总览

总览展示数据规模、High标签占比、平均AI依赖和模型宏平均F1。全局SHAP卡展示真实模型整体最依赖的前10项字段及归一化重要性；它只描述模型使用信息的程度，不表示正负方向或因果关系。专业图展示各专业High占比，年级图展示平均依赖。所有数值来自后端聚合产物；如接口断开，页面会显示“服务未连接”。

## 4. 风险评估

按页面分组填写专业、年级、学期前GPA、AI时长、主要用途、提示技能、工具数量、订阅、传统学习时长、感知依赖、AI政策和考试焦虑。页面不要求姓名和学号。检查知情说明后提交。

结果区首先显示High概率和Low/Medium/High三类完整概率，然后显示主要SHAP因素与建议。正SHAP表示该因素推动当前模型风险方向，负SHAP表示抑制；它不是因果结论。

## 5. 结果处理

- Low：保持主动学习和定期自检，不代表未来无风险。
- Medium：检查AI与传统学习比例、睡眠/任务压力，必要时与教师沟通。
- High：优先由辅导员或教师结合正式量表和访谈复核；不得自动处分。

如存在即时人身安全问题，应直接联系学校既有应急/心理支持渠道，不等待本系统结果。

## 6. 公平性页面

TPR表示真实High样本被识别的比例，FPR表示非High样本被误报High的比例，选择率表示该组预测High比例。状态只用于提示复核；专业或年级不是个人命运，也不能据此评价群体。

## 7. 常见问题

“服务未连接”：确认后端已启动、端口未被占用、模型产物存在。  
“预测响应无效”：检查模型与后端版本是否一致，概率是否齐全。  
表单无法提交：查看字段下方中文错误，修正范围或遗漏。  
SHAP较慢：首次解释可能初始化，稍后重试；不要重复点击。  
页面有数据但预测失败：查看`/api/health`模型状态。

## 8. 隐私

演示前端不使用本地存储，后端默认不落库。仍不建议输入真实姓名、学号、联系方式或自由文本。生产部署必须另行实现权限、加密、保存期限和删除机制。
