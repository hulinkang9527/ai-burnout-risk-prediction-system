# 系统设计说明书

## 1. 架构

系统由原生JavaScript前端、FastAPI服务、scikit-learn模型管线和版本化JSON/NumPy产物组成。API置于`/api`，静态前端由同一进程托管。训练数据不由线上服务直接读取；服务仅加载模型和聚合产物。

## 2. 模块

前端包括导航与状态、总览卡片、全局SHAP条形图、专业柱图、年级折线、风险表单、概率仪表、局部SHAP贡献、建议、公平性表和伦理说明。后端包括配置、Pydantic模式、产物仓库、预测服务、SHAP服务、建议策略、路由和静态文件托管。

## 3. 数据流

训练阶段：CSV→质量检查→字段白名单→分层划分→预处理/模型→指标/SHAP/公平性→版本化产物。推理阶段：浏览器表单→前端校验→Pydantic校验→字段映射→模型概率→SHAP→建议→JSON→界面。

## 4. 模型接口

`model.joblib`应包含从原始12字段到概率的完整管线。模型类别顺序必须从`classes_`读取，不硬编码数组位置。SHAP背景与转换后特征名必须同版本。任何维度不匹配都应使服务健康状态降级。

## 5. 接口

- `/api/health`：服务与模型状态。
- `/api/metadata`：字段枚举、范围、模型版本、数据限制。
- `/api/dashboard`：聚合统计、分组趋势和全局SHAP前10项。
- `/api/predict`：三类概率、局部SHAP、建议和声明。
- `/api/fairness`：专业/年级TPR、FPR、选择率与状态。

## 6. 异常处理

输入错误返回422；模型未加载返回503；产物格式错误返回500或服务降级；未知路由返回404。前端对网络错误、超时、非2xx、非JSON和缺失概率分别提示，不填入演示值。

## 7. 安全与部署

本地演示不落库。生产扩展需要反向代理TLS、认证、角色授权、请求速率、CSP/安全头、只读模型目录、哈希校验、敏感日志清理、备份和漂移监控。High风险不触发自动外部操作。

## 8. 可访问性

表单控件具有label，错误使用aria属性关联；图表保留数值文本/表格；键盘焦点可见；移动菜单支持Esc；reduced-motion关闭非必要动画；设计在200%缩放下应保持操作路径。
