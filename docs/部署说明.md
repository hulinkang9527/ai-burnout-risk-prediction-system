# 本地部署说明

## 环境

建议使用Python 3.13；当前模型产物由Python 3.13.14及`metadata.json`所列依赖版本生成。终端为Windows PowerShell或兼容环境，训练与服务依赖见各目录requirements文件。浏览器建议使用当前版本的Edge、Chrome或Firefox。

## 生成模型

在项目根目录运行`python 03_数据分析/analysis_pipeline.py`。脚本从工作区的原始数据目录只读加载CSV，输出`artifacts/model.joblib`、`metrics.json`、`metadata.json`、`dashboard.json`、`fairness.json`、`shap_background.npy`和转换后特征名。训练结束后核对退出码和指标文件，不能只看模型文件是否存在。

## 启动服务

进入`02_系统源码/backend`并运行`run.ps1`。服务启动时检查模型、JSON和前端目录。访问`/api/health`，只有model状态为ready时才进行预测。首页由同一服务托管。

## 生产扩展

当前配置只适合本地演示。生产环境应：使用固定依赖版本和容器镜像；非root运行；只读挂载模型；在反向代理启用TLS、认证、速率限制和安全头；关闭公开调试；限制CORS；集中日志但清理敏感字段；配置健康检查、备份、指标监控、输入漂移与模型回滚。

## 故障排查

- 模型unavailable：重新运行训练脚本或检查产物路径。
- 维度不匹配：模型、SHAP背景和特征名不是同一版本，全部重新生成。
- 422：按错误详情修正字段名、范围或枚举。
- 页面404：确认frontend目录与backend相对位置未改变。
- 端口占用：按README修改端口，避免同时运行多个实例。
