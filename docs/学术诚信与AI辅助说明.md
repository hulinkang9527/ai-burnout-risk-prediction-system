# 学术诚信与AI辅助使用说明（提交前由本人和导师确认）

本毕业设计使用生成式人工智能辅助完成资料组织、代码草拟、语言修改、文档排版和测试检查。学生本人应对选题、数据使用、模型设计、代码运行、实验结果、引用准确性、论文陈述和最终提交承担全部责任。

提交前应完成以下人工核验：

1. 亲自运行训练与测试，确认论文指标与`metrics.json`、`fairness.json`一致。
2. 阅读并理解所有代码，能够在答辩中解释数据处理、模型、SHAP、接口和限制。
3. 逐条核验参考文献真实存在且正文引用匹配，删除无法验证的文献。
4. 按学校规定进行重复率与AIGC检测，并根据指导教师意见修改。
5. 获取当届关于生成式AI辅助毕业论文的正式规定；如要求披露，按指定位置和格式提交本说明。
6. 不把AI生成内容冒充真实访谈、问卷、伦理审批、部署记录或实验结果。
7. 诚信声明、签名、日期和指导教师意见必须由相应人员本人填写。

建议披露表述：

“本研究在资料整理、编程辅助和语言校对环节使用了生成式人工智能工具。作者对工具输出进行了人工核验，独立完成研究设计、实验运行、结果解释与最终定稿，并对全文准确性和学术诚信负责。”

是否采用该表述以及放置位置，以学院和指导教师要求为准。
