# AI依赖与学业倦怠预测系统需求规格说明书

版本：1.0　作者：胡林康（23280128）

## 1. 目标与范围

系统以Kaggle模拟/合成性质数据为基础，为毕业设计提供数据探索、倦怠三分类预测、SHAP解释、专业/年级比较和公平性审计。系统不是医疗器械、心理诊断工具或学生管理自动决策系统。

## 2. 用户与场景

- 学生：匿名填写12项学习与AI使用信息，查看概率、解释和支持建议。
- 教师/辅导员：查看聚合趋势和分组性能，结合正式量表与访谈人工复核。
- 研究者/开发者：检查模型版本、指标、接口、SHAP和公平性限制。

## 3. 功能需求

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-01 | 系统总览 | 展示样本数、High占比、平均依赖、Macro-F1 |
| FR-02 | 专业比较 | 展示各专业样本量与High占比 |
| FR-03 | 年级比较 | 展示各年级样本量与平均AI依赖 |
| FR-04 | 风险表单 | 支持12字段、中文标签、范围与枚举校验 |
| FR-05 | 概率预测 | 返回Low/Medium/High且和约等于1 |
| FR-06 | 全局与局部解释 | 总览展示全局SHAP前10项；预测返回当前样本主要SHAP正负贡献 |
| FR-07 | 支持建议 | 由后端按等级返回非诊断建议 |
| FR-08 | 公平性审计 | 按专业/年级展示TPR、FPR、选择率、状态 |
| FR-09 | 数据与伦理 | 展示来源、证据边界、人工复核和隐私说明 |
| FR-10 | 错误状态 | 接口断连/超时/非法响应时不得显示伪造数据 |

## 4. 非功能需求

- 可用性：360px至桌面宽度可操作；错误保留输入并聚焦字段。
- 可访问性：语义HTML、键盘焦点、文本替代、非颜色单一编码、reduced-motion。
- 性能：本地单次预测目标响应时间小于2秒；SHAP超时应返回可解释错误。
- 安全：后端独立校验；限制请求体；不记录直接身份信息；静态资源同源。
- 隐私：演示版无姓名/学号字段，不落库、不使用浏览器持久化。
- 可追溯：响应包含模型版本；产物包含数据指纹与训练时间。
- 可靠性：模型缺失时健康状态degraded、预测503，其他静态说明仍可访问。

## 5. 数据约束

输入字段为major_category、year_of_study、pre_semester_gpa、weekly_genai_hours、primary_use_case、prompt_engineering_skill、tool_diversity、paid_subscription、traditional_study_hours、perceived_ai_dependency、institutional_policy、anxiety_level_during_exams。禁止把Student_ID、Post_Semester_GPA和Skill_Retention_Score加入在线预测。

## 6. 业务规则

Low、Medium、High均为模型风险等级而非诊断。High应显示“优先人工复核”，但不自动联系、处分或转介；任何行动由有权限人员结合正式量表和情境决定。SHAP描述模型归因，不写成因果关系。

## 7. 不在当前范围

真实学生身份认证、长期个人档案、危机热线、校内业务系统集成、医疗诊断、移动App、跨校生产部署、性别/年龄等敏感属性公平性验证不属于当前演示版。
