# 真实数据采集与多模态扩展方案

## 1. 目的

当前Kaggle数据全部为结构化字段，不能据此宣称已经完成真正的多模态学习。未来若要验证“AI依赖—认知惰性—学业倦怠”机制，可在伦理审批和知情同意基础上，收集结构化问卷、学习平台行为序列与自愿文本反思三类信息，并采用后融合而非直接拼接身份数据。

## 2. 建议模态

### 结构化问卷

人口统计最小必要信息、专业/年级、课程负荷、AI时长与用途、核验/改写习惯、传统学习时长、考试焦虑、睡眠、社会支持和正式学业倦怠量表。量表必须使用经验证且获授权的版本，不能自行改写后仍沿用原量表名称。

### 行为时序

经课程和学生授权后，收集去身份化的学习平台访问、提交时间、复习间隔、主动练习和AI辅助次数。禁止采集无关浏览历史、私人聊天或设备全量日志。原始行为按周聚合，并设置最短保存期限。

### 文本反思

学生可自愿提交短篇学习反思，用于识别任务负荷、挫败、控制感和AI核验策略。文本应先去除姓名、教师、课程编号和其他身份线索；情绪模型只能作为辅助信号，不能把关键词直接等同心理状态。

## 3. 标签与时间设计

建议至少三个时间点：学期初基线、学期中预警、学期末结果。预测特征截止到学期中，标签由同一时点或后续经过验证的量表产生；学期后成绩和技能保持只能用于结果验证，不进入学期中模型。可使用纵向混合模型、时间到事件分析或跨滞后设计研究方向性。

## 4. 多模态融合

每种模态先独立编码并验证：结构化特征使用树模型，时序使用统计聚合或序列模型，文本使用经过中文教育语境验证的嵌入。后融合阶段组合各模态概率或表示，并通过消融实验比较“仅结构化”“结构化+行为”“全部模态”。任何复杂模型都要与简单基线比较，并报告缺失模态下的性能。

## 5. 公平性与伦理

敏感属性只在确有公平性评估必要、获得审批且采用最小化原则时收集。公开结果需设置最小组样本量并抑制小单元；模型训练与身份映射分离；学生可拒绝、撤回并请求删除。预测不得自动影响成绩、奖惩或资格。

## 6. 样本量与验证

先开展小规模认知访谈与问卷预测试，检验条目理解；再根据主要模型、类别比例和分组分析做功效/样本量规划。最终至少需要跨课程或跨学校的外部测试，并报告校准、决策曲线、High召回、组间差异和置信区间。

## 7. 预期产物

研究方案、伦理审批、知情同意书、数据字典、量表授权记录、去标识化流程、数据管理计划、分析注册、模型卡和干预手册。上述材料齐全前，不应把原型直接部署到真实学生管理流程。
